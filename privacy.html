🦉 Politique de confidentialité — Hibou Empire

Dernière mise à jour : 2026.

1. Données traitées

Cette application est un outil interne à usage strictement personnel (un seul administrateur). Elle ne collecte aucune donnée d'utilisateur tiers. Les seules données stockées sont : le compte administrateur (email), et le contenu généré pour publication (textes, images, statut de publication).

2. Stockage

Les données sont hébergées sur Supabase (base de données et stockage de fichiers). Aucune donnée n'est revendue ni partagée avec des tiers.

3. Réseaux sociaux

L'application publie du contenu sur Instagram et TikTok via l'API Postiz, au nom du compte "Hibou Empire", avec l'autorisation explicite de son opérateur via connexion OAuth.

4. Contact

Pour toute question : contact via le profil Instagram/TikTok @hibou.empire.
